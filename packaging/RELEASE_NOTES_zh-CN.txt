Bloodborne PC 中文懒人版更新说明

v1.6.5（2026-10-11）
- 原生联机地址指向本机（127.0.0.1、本机名或本机局域网 IPv4）且 WebAPI 未监听时，自动启动内置 shadNet，不再因为漏勾“本机服务器”而直接报无法连接。
- 启动前先复用已经在线的本机服务器，避免重复启动造成端口占用；本机服务器启动失败时给出针对 shadnet.exe、防火墙和注册密钥的提示。
- shadNet 登录错误 6／7／8 现在分别显示“账号已在别处登录／NPID 未注册／密码错误”，便于区分网络不通与账号认证失败。

v1.6.4（2026-10-11）
- 原生 bbport 联机不再使用仅返回“已登录”的最小局域网桩；完整移植 shadp2p 的网络、NP Manager、NP Auth、WebAPI、Matching2、Signaling 与 P2P socket 协议栈。
- “原生在线联机”会实际连接所填 shadNet 的 TCP 31313、UDP 31314 和 WebAPI TCP 31315，并使用已注册的 NPID 与密码完成认证。
- 启动前先检测 shadNet WebAPI；本机开服时自动等待服务就绪，避免进入游戏后才笼统提示“无法连接服务器”。
- 完整打包 Protobuf、OpenSSL、zlib 与所需 Abseil 运行库；仍保留独立 shadp2p 核心作为兼容测试方案。
- 保留 v1.6.3 的 Windows 内存池按需提交修复、低显存配置、存档管理、金手指和输入映射。

v1.6.3（2026-10-11）
- 修复 Windows 在启动时用 SEC_COMMIT 一次性提交完整约 6 GiB 客体内存池，低内存／页面文件紧张的电脑因此报 Windows 错误 1450 或 1455 并以 139 退出的问题。
- 内存池现在先保留地址空间，再只为游戏实际分配的物理范围按需提交；不会改变游戏可见的 5056 MiB 直接内存容量，也不降低画质。
- 139 崩溃摘要会保留内存池、Windows 1450／1455 和 Dantelion2 分配失败信息，并显示有针对性的内存与虚拟内存处理建议。

v1.6.2（2026-10-11）
- 修复原生局域网模式只报告 NP 已登录、但旧版 NP Signaling 与 NP Lookup 仍返回“未登录”，导致游戏强制进入离线模式、共鸣钟道具变灰的问题。
- 补齐旧版信令初始化、上下文、连接状态，以及玩家在线 ID 查询的完整生命周期，并与现有局域网对端地址衔接。
- 补充 Matching2 大厅查询、加入／离开和延迟查询的成功回调，避免遗漏的在线接口再次把游戏降级为离线。
- 原生局域网启动时自动记录“Native NP”初始化轨迹，方便根据运行日志继续定位实际游戏中的联机流程。
- 新增在线启动门槛测试，覆盖登录状态、Plus 回调、玩家查询、旧版信令与 Matching2 初始化。

v1.6.1（2026-10-10）
- 原生 bbport 局域网进入第三阶段：新增 UDP 房间发布／发现、加入请求／确认与离开通知，不再只停留在“在线初始化成功”。
- 接通 Matching2 创建、搜索、加入和离开房间回调，以及成员加入／离开和信令建立事件；加入后可查询对端 IPv4 与 P2P 端口。
- 房间广播会携带最多 8 个可搜索整数属性和首个可搜索二进制属性，用于识别兼容的 Bloodborne 房间。
- 原生模式固定使用 UDP 31314 发现端口和 UDP 31316 P2P 端口，并在界面明确提示 Windows 防火墙要求。
- 新增独立双端回环测试和穿过 Matching2 适配层的端到端测试，覆盖创建、发现、加入、成员回调、信令地址与离开。
- 仍属于开发预览：协议和回调链路已验证，但铃铛匹配与实际 P2P 游戏数据需要两台电脑实测后继续补齐。

v1.6.0（2026-10-10）
- 新增“原生局域网（bbport，开发预览）”启动模式：直接使用 bbport，不再切换到整套 shadPS4 核心，并保留现有画质、键鼠、手柄映射、金手指和存档环境。
- 第一阶段原生网络已完成：Windows TCP／UDP、DNS、socket 选项、WSAPoll 事件等待和 shadp2p 兼容的 P2P 虚拟端口帧；默认单机模式仍保持断网行为。
- 第二阶段在线初始化已完成：可配置联机 ID、NP 已登录状态与回调、Matching2 初始化、上下文启动／停止，以及单一局域网世界回调。
- 当前是开发预览：房间发现、加入房间和玩家间信令尚未完成，因此原生模式暂时不能保证摇铃匹配；需要立即联机时继续使用“shadp2p 联机”模式。
- 新增真实 127.0.0.1 UDP／P2P 收发测试和 NP／Matching2 生命周期测试；同时修复便携依赖目录已应用 FSR 补丁时，Windows 构建错误地重复应用补丁的问题。

v1.5.2（2026-10-10）
- 重做“版本与更新”页面：版本标题分级突出、每条改动逐行显示，并增加阅读提示和版本间距。
- 点击“安装 / 更新运行环境”时新增配置提示：建议至少 4 GB 显存、16 GB 内存和 16 GB Windows 虚拟内存。
- 配置提示内加入 Windows 虚拟内存的设置路径、建议数值和重启说明。

v1.5.1（2026-10-10）
- 修复 720p／1080p 在关闭实时分辨率时仍申请约 10 GiB 系统提交内存，导致低内存电脑报 Windows 错误 1455 并以 139 退出。
- 720p／1080p 现在使用游戏原生的 5056 MiB 直接内存预算；1440p／4K 继续保留 9152 MiB 高分辨率预算，不改变画质和正常情况下的帧率。
- 游戏内改变输出分辨率并重启时会重新计算自动内存预算；手工设置的 BB_DMEM_MB 仍保持最高优先级。

v1.5.0（2026-10-10）
- 选择性移植 Linux 分支的稳定性成果：修复 Vulkan 命令记录块切换时的空指针竞争，降低区域切换／高负载下的随机 139 崩溃。
- 纹理回收改用真实闲置时间；普通显存水位下默认仅回收 20 秒未使用的纹理，避免高速提交时反复删除、上传刚离开画面的资源。
- Shader 缓存、游戏存档和存档元数据改为“临时文件写完并落盘后再原子替换”，意外退出或断电时保留上一份完整文件；启动时自动清理中断留下的临时存档。
- 启动前验证 CUSA03173 1.09 的 eboot，并检查 Shader DCX 是否损坏，把加载卡死、补丁越界等问题提前显示为明确的中文错误。
- 新增《老猎人》DLC 授权开关，兼容 shadPS4 的 addcont 目录布局；只创建授权目录，不包含或下载游戏文件。
- 修复姿势／个人效果菜单的触摸输入：触点现在有持续且非零的 ID，并正确报告按住时间；Tab、Xbox View／Select 和触摸板映射更可靠。
- 未直接移植 Linux 0.5 的实验性缓冲区显存模型和异步管线；它们与 Windows 当前内存映射实现耦合较深，暂不用于玩家版。

v1.4.0（2026-10-09）
- 新增可选 shadp2p 局域网联机核心，并打包匹配版本的 shadNet Windows 服务端。
- 新增“局域网联机”页面：支持本机一键开服、服务器状态检测和账号注册。
- 自动生成 shadPS4 网络配置、用户配置与 host_overrides.json，支持传统联机和实验性无缝联机。
- 联机核心使用独立且稳定的玩家数据目录；存档管理、导入导出和自动备份会随当前核心切换。
- 联机账号密码与服务器注册密钥在启动器状态文件中使用 Windows DPAPI 加密；shadPS4 自身仍按上游格式保存联机凭据。
- 启动非 CUSA03173 1.09 游戏时显示兼容性警告；当前上游只确认该区域版本。
- 明确提示 shadNet 只应运行在可信局域网，禁止将未加密的服务端口转发到公网。

v1.3.2（2026-10-09）
- 修复旧配置同时启用“敌人控制”和“调试相机”时无法启动游戏。
- 两项功能现在在界面中自动互斥；读取旧配置时保留最后一项并自动关闭另一项。
- 保留核心启动前冲突校验，防止共享控制逻辑被两个补丁重复改写。

v1.3.1（2026-10-09）
- 修复无限血、无限血之回响和强化材料启动时报“address is outside the eboot”。
- 为 CUSA03173 v1.09 训练器使用的空白代码页注册只读／可执行映射，同时继续严格拒绝其他越界补丁。
- 新增真实 eboot 分段边界回归测试，覆盖 91,042,036 字节游戏镜像。

v1.3.0（2026-10-09）
- 新增完整手柄映射：A／B／X／Y、肩键、扳机、摇杆按下、Start、Select、触摸板和十字键均可改为任意游戏动作或取消绑定。
- 手柄改键会随启动器设置保存，并提供一键恢复默认；View／Select 默认保持为触摸板左侧姿势菜单。
- 新增无限血、无限血之回响和随意强化武器金手指；强化功能通过材料／物品不减且获取或购买后变为最大实现。
- 新金手指代码以 CUSA03173 v1.09 为已验证目标，其他区域在界面中明确标为实验功能；启用前仍会自动备份存档。
- 无限血与旧“不死”补丁互斥，避免两个生命值钩子同时启用造成冲突。

v1.2.0（2026-10-08）
- 恢复 FSR 4 v07、FSR 4.1.1、DLSS、TAA、FSR 3.1 和关闭等完整升频选项。
- 安装包内置可再分发的 FSR 4 v07 全模型和 NVIDIA DLSS 模型；FSR 4.1.1 因授权限制保留自备模型入口。
- 金手指加入常用辅助预设、灵敏摇杆、娱乐物理、敌人控制和调试相机，并区分实验功能。
- 存档管理可读取并修改角色名；修改前自动备份，写入后再次校验。
- 外部存档兼容 userdata0000、userdata_0000、userdata-0000 及带 .bin／.sav 后缀的常见命名，导入时规范化为游戏所需文件名。
- Xbox View／Select 现在强制映射到左触摸板姿势菜单，不再受其他虚拟手柄残留触摸干扰。
- DualShock／DualSense 等支持传感器的手柄会传递加速度、角速度和姿态数据，修复体感姿势输入。
- 启动器加入原创哥特猎人城市景观背景。

v1.1.1（2026-10-08）
- 修复导入／读取外部存档后进入场景可能出现的 139 崩溃。
- GPU 地址校验现在会区分已提交内存与仅保留的 MEM_RESERVE 区域。
- 已失效的零长度缓冲改为绑定空描述符，不再交给页追踪器。
- 纹理脏数据哈希改从受 VMA 锁保护的后备视图读取，避免 DrawRec 与场景内存释放竞争。

v1.1.0（2026-10-08）
- 修复动作输入：同时读取全部已连接手柄，Steam 虚拟手柄、方向盘或休眠设备不再抢占真实手柄。
- 键盘、鼠标和手柄动作可同时生效，不再因检测到其他控制器而关闭键盘动作。
- 启动前校验已安装核心版本，旧核心会明确提示先执行“安装 / 更新运行环境”。
- 新增“版本与更新”页面，可直接查看当前版本和历次更新内容。
- 加强手柄回归测试，覆盖“第一个控制器无输入、第二个控制器有输入”的 Windows 常见场景。

v1.0.0（2026-10-07）
- 首个中文单文件安装／启动器版本。
- 内置 Windows 运行环境，无需 Python 或重新编译。
- 加入完整键鼠映射、改键、鼠标视角、存档管理、自动备份、外部存档验证与导入。
- 加入画质推荐方案、金手指、居中姓名输入弹窗和更详细的退出码 139 诊断。

版本规则
- 每次向玩家发布新的 EXE 都递增版本号，并在本页面追加对应说明。
- 更新后请点击“安装 / 更新运行环境”，确保内置核心和安装目录版本一致。
