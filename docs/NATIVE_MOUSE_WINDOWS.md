# Windows 原生鼠标视角（实验性）

启动器「输入与手柄」→「鼠标」可开启「原生鼠标视角」。此模式在 Bloodborne 1.09 的镜头更新处接收 SDL 相对鼠标位移，直接调整镜头俯仰和朝向，不把自由视角移动转换成右摇杆值。视角转动不受摇杆速度上限与死区限制。锁定目标时游戏自己控制镜头，鼠标位移不会再注入右摇杆，避免目标随鼠标漂移；需要切换锁定目标时可使用方向键视角或实体手柄右摇杆。鼠标按键、滚轮与键盘动作仍通过游戏原有的 `scePad` 输入接口。它**不是**完整的原生键鼠动作系统。

WASD 步行斜向按单位圆缩放；奔跑时采用方形摇杆门限，并将方向突变分成数帧，减少 `W` 转 `W+A` 时游戏误判为停止奔跑。左右输入对称，实体手柄输入不受影响。如果仅 `左 Shift+W+A` 一类组合掉键、而 `右 Shift+W+A` 或鼠标侧键映射为「奔跑／闪避」正常，通常是键盘矩阵的组合键冲突。启动器可在「输入与手柄」把奔跑改绑到右 Shift，或将鼠标侧键映射为「取消／闪避 ○」，让键盘只需同时按 W+A。修改后保存设置并重启游戏。

「输入与手柄」可将静步设为任意键（默认左 Ctrl），并调整移动幅度（默认 0.45）；它仅缩小键盘 WASD 的虚拟左摇杆，不影响实体手柄。静步和奔跑同时按下时奔跑优先。另有两个可独立设置的键盘双键快捷键：选择按住键、主键及触发的游戏动作；两键同时按下时，主键的普通动作被快捷键取代，按住键原有的动作仍保留。建议用未占用的右 Ctrl 等键作按住键，避免 Shift 的闪避／奔跑副作用。快捷键不是自动连招。

为保护现有手柄、在线联机和其他游戏版本，启动时先验证 1.09 镜头入口和四处写入点的原始指令。任一位置不符就不安装补丁，保留现有摇杆视角。游戏开始执行之前安装；切出窗口、打开设置或按 F10 释放鼠标时会清空待处理位移，避免返回游戏后视角跳动。

独立运行时可设置 `BB_MOUSE_CAMERA=direct`，`BB_MOUSE_DIRECT_SENSITIVITY=1.0`（范围 0.1–10），`BB_MOUSE_INVERT_Y=1`。`BB_MOUSE_CAMERA=stick` 恢复旧模式；该设置不会改变手柄输入。查看启动日志中的 `Mouse camera: native direct mode active` 确认已启用，若看到 `signature mismatch` 则说明游戏映像不匹配，不能强行安装。

静态与合成映像测试不等于实机游戏验证。发布前仍需在 1.09 游戏中检查自由视角、锁定切换、单筒望远镜、菜单、Alt-Tab、F10，以及 BBSC 会话中镜头与键盘动作互不干扰。后续若要求键盘动作也完全绕开 `scePad`，必须另行定位并验证游戏内部动作/菜单输入入口，不能仅靠改键达成。
