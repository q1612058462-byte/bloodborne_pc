# Windows HDR10

启动器「设置 → HDR10 输出（实验）」默认关闭。先在 Windows 显示设置中开启 HDR，并使用支持 HDR10 的显示器；之后勾选该选项，设置显示器峰值亮度与普通画面亮度，再启动游戏。检测不到可用 HDR10 输出时，渲染器自动回退到原有 SDR 呈现。

Bloodborne 原始画面为 SDR。本功能仅在最终呈现阶段把 SDR 转换为 BT.2020 / PQ HDR10，并适度扩展亮部；它不是原生 HDR 素材，也无法还原原本不存在的高动态范围细节。亮部过曝、色彩异常或帧率下降时，关闭该选项即可回到旧 SDR 路径。开启/关闭该选项需重启游戏。

实现保持游戏和原有升频输出为 SDR，最后单独使用 HDR10 交换链和后处理通道；这样在 Windows HDR 状态变化或不支持的设备上可以回退，不改变既有 SDR 行为。当前没有真实 HDR10 设备的自动化视觉测试，故仍标为实验。

## 《老猎人》DLC

启动器已移除 DLC 勾选和确认项，默认建立原有的《老猎人》兼容授权目录。此操作不下载或补齐游戏内容；仍需使用自己合法取得的完整游戏文件。
