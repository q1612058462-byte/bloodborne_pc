查看 Windows 项目与说明 ↗
  1. 01

    准备合法的游戏数据

    需要 Bloodborne 1.09 的解密游戏目录；本项目及网站不分发游戏文件。

  2. 02

    设置启动器

    在“设置”中选择游戏目录和玩家数据目录，安装运行环境。建议先用保守画质完成首次启动。

  3. 03

    选择联机方式

    传统在线与“在线无缝联机”分别提供准备入口。首次申请账号需联机 ID、密码、QQ 号与昵称；以后可使用已保存的信息。

  4. 04

    启动与备份

    无缝模式会在启动前检查服务并备份存档。若自动流程失败，再按启动器中的手动步骤逐项排查。

05 · 常见问题

在出发之前。

网站能直接下载游戏吗？

不能。这里只介绍并链接到社区制作的程序与源码，不提供游戏本体、密钥或存档。你需要自行准备合法取得、适配 1.09 的游戏数据。

现在有公开的 Windows 安装包吗？

请以项目 GitHub 的 Releases 页面为准。若页面暂无发布版本，说明当前仍处于测试阶段；不要从来路不明的镜像下载。

无缝联机需要与对方在同一个局域网吗？

不需要，但两端都要完成账号准备并连接内置私网。若不能加入，先确认双方私网状态、游戏版本和启动器日志。

专用联机道具没有立即出现怎么办？

先确认已有可读取的角色存档。无缝模式在发放道具前需要完成备份；首次创建角色后可正常存档、退出，再重新启动无缝模式检查。

游戏报错或突然掉线时先做什么？

保留双方的游戏与 BBSC 日志，记录发生时间。复杂启动错误可先备份存档，再尝试清理存档中的 cache 或用户目录下的 shadPS4 缓存；不要删除正式存档。
